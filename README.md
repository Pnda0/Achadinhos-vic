# Achadinhos da Vic

Grupos de ofertas por nicho — **Fitness**, **Beleza** e **Perfumes** — com achadinhos do Mercado Livre, da Amazon e de lojas parceiras (Awin), filtrados.

- [Vic Site/](Vic%20Site/) — página de entrada (https://achadinhos-vic.pages.dev): os três grupos, cada um com o seu botão de convite.
- [ml-afiliados/](ml-afiliados/) — bot que coleta as ofertas, gera os links de afiliado e posta em cada grupo. Veja o [README do bot](ml-afiliados/README.md).

O canal "Geral" (de tudo) continua funcionando no bot, mas não é divulgado no site.
